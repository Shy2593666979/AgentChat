# 分析结果结构

1. 输入范围：数据来源、字段、单位、样本范围。
2. 数据质量：问题｜涉及字段｜影响｜建议处理方式。
3. 指标口径：指标｜公式｜分母与窗口｜来源。
4. 主要发现：观测结果｜可能解释｜尚需验证的条件。
5. 后续分析：需要哪些补充数据；如需绘图，说明图型、横纵轴与单位。

计算示例：本月销售额 120、上月 100，单位一致且范围相同时，环比增长率为 `(120 - 100) / 100 = 20%`。上月为 0 时，不能输出有限的增长百分比。

使用示例：用户提供按月订单汇总，要求解释转化率下降。先确认转化率的分母是访问用户、会话还是线索，再比较同一口径；只有订单数量时不能计算转化率。
