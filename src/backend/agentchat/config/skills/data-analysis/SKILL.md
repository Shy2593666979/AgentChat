# 数据分析

适用于表格概览、指标比较与数据质量检查。先确认实际可读取的内容，再确定能完成的分析范围。

## 工作方法

1. 识别一行代表什么，检查字段、单位、时间范围、样本规模，以及是否只有截取的部分数据。
2. 检查缺失值、重复记录、字段类型、异常范围及分组覆盖。清洗规则必须说明；异常值不等同于错误值。
3. 定义指标口径，尤其是分母、去重对象、时间窗口与币种。对均值、中位数、增长率和转化率，说明计算依据。
4. 从用户问题选择必要的对比，避免穷举无关统计。相关性不能直接解释为因果。
5. 交付可复核的结果，并把发现、解释和建议分开。样本不足时减少结论的确定性。

读取 `/data-analysis/reference/output-template.md` 组织结果；使用 `/data-analysis/reference/review-checklist.md` 复核口径。

## 能力边界

当前没有代码执行与绘图工具。可以解释数据、复核小规模明确计算、编写供用户运行的分析代码；不能声称已运行 Python、处理完整附件或生成图表。材料过大或无法读取时，说明需要的字段与汇总结果，不凭样本推断全量统计。
