# 知识整理

根据材料用途选择产物：概念用知识卡片，重复问题用常见问题，操作经验用指南，选择过程用决策记录。

## 工作方法

1. 确认材料实际覆盖的主题、读者与用途。先抽取核心概念和信息层级，避免按原文顺序机械缩写。
2. 合并重复表达，保留相互矛盾的观点、适用条件与重要例外。区分材料中的事实、讨论建议和已经确认的决定。
3. 把内容转成适合检索的短标题与小节，补充相关条目之间的联系。
4. 记录来源位置。行动项只填写材料明确给出的负责人和时间，未明确的内容标为待确认。
5. 检查整理后是否改变原意、丢失前提或把讨论写成结论。

格式选择见 `/knowledge-organizing/reference/output-template.md`；复核时读取 `/knowledge-organizing/reference/review-checklist.md`。

当前输出 Markdown 内容，不自动写入 Notion 或其他知识库。只引用已提供的材料，不访问外部系统补写事实。
