# 邮件写作

产出可直接审阅的邮件草稿。已有草稿时优先保留原意，按用户要求调整语气、结构或语言。

## 工作方法

1. 从请求中提取收件人关系、沟通目的、语言与语气。事实已足够时直接起草；缺少会改变邮件含义的内容时再询问。
2. 用主题说明事项，用开头说明目的，正文只保留收件人需要的信息。
3. 将希望对方执行的动作、需要回复的问题和已提供的期限写清楚。用户没有提供期限或承诺时，不自行编造。
4. 对延期、拒绝或投诉回复，说明已知事实与可行下一步，避免替用户承认未经确认的责任或作出未经授权的承诺。
5. 润色后核对姓名、日期、金额、附件描述和行动要求是否与原材料一致。

场景选择与结构见 `/email-writing/reference/output-template.md`；发送前可用 `/email-writing/reference/review-checklist.md` 复核。

当前只生成草稿，不发送邮件、不添加真实附件。缺少署名或姓名时省略，或明确标为待补充信息，不声称已经发送。
