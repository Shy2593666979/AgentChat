# 研究报告

用于需要明确研究问题、比较资料并形成有依据结论的任务。直接解释一个概念时，不必套用完整报告。

## 工作方法

1. 从请求中提取研究问题、读者、时间范围与比较维度。缺少决定结论的关键信息时，只询问必要内容。
2. 将提供的材料按问题归类，记录作者或机构、日期、来源链接或材料编号。来源内容相互矛盾时，保留分歧并说明可能原因。
3. 分别标记材料中的事实、作者观点和自己的推断。引用必须能定位到实际提供的材料；没有材料支持的说法不能写成确定结论。
4. 围绕研究问题组织分析，解释各结论的依据、适用范围及不确定性。对比方案时使用一致维度。
5. 给出能够回答原问题的结论，并列出仍需补充的证据。

组织报告时读取 `/research-report/reference/output-template.md`；交付前读取 `/research-report/reference/review-checklist.md`。

## 能力边界

当前可以读取技能文件与用户在对话中提供的资料。没有联网检索工具时，不声称检索过网页；用户只给链接而未提供正文时，说明该来源尚未核实。需要最新信息时，让主智能体补充检索材料。不要编造文献、数据或引文。
