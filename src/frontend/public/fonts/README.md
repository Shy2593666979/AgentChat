# AgentChat UI fonts

Inter Variable: https://github.com/rsms/inter (SIL OFL 1.1).
Noto Sans SC Variable: https://github.com/notofonts/noto-cjk (SIL OFL 1.1).
The Noto WOFF2 subset retains GB2312 Chinese characters, UI source characters, ASCII and common CJK punctuation. Uncommon user-supplied characters use the configured system fallback.
Original license notices are included next to the font files.
