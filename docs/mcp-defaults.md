# MCP 默认配置与异步生成

默认服务现在先加载为系统模板，再为每位用户复制独立记录。页面仅展示个人服务，编辑或删除不影响其他用户；详见[用户私有资源](private-resources.md)。

默认服务为高德地图、必应搜索、Parallel 搜索，配置位于 `src/backend/agentchat/config/mcp_server.json`。`mcp_as_tool_name` 与 `description` 固定写入 JSON。

启动时只为缺失的默认服务创建系统模板，名称、工具名和描述直接读取 JSON；配置缺少名称或描述时明确报错。不连接远端 MCP，不调用模型，不按更新时间刷新。已有记录保留 ID、配置与工具参数，启动不执行旧数据清理。

用户添加 MCP 后，接口先保存服务、返回 ID，再通过 `asyncio.create_task` 在当前进程内发现工具并生成名称和描述。同步模型调用使用 `asyncio.to_thread`，不会阻塞 HTTP 事件循环。修改用户服务连接配置时也异步重新生成；只改展示名称或 Logo 不触发生成。

没有新增数据库表。生成状态只保留在进程内，通过服务列表的 `metadata_status`、`metadata_error` 返回。失败可调用 `POST /api/v1/mcp_server/{server_id}/metadata/retry`，页面也提供重试按钮。后端重启不会自动恢复任务；首次生成被中断的记录会显示可重试状态。多个后端进程之间不共享任务状态。

默认配置中的 `tools`、`params` 保存经过实际连接验证的工具快照，分别包含工具名称和描述、输入参数。页面从个人服务记录读取这些信息，启动和页面加载不实时联网刷新；高德地图 12 个工具，必应搜索 2 个，Parallel 搜索 2 个。新用户直接复制这些模板信息。实际执行工具时，MCP 客户端仍连接远端服务获取当前工具定义。
