## 设计判断

整套图适合用作 AgentChat 的前端设计基准。蓝白背景、深蓝文字、浅蓝描边、白色圆角面板和绿色完成状态贯穿各页面，主要操作容易识别。星球和透明方块是品牌装饰，应放在背景层，不阻挡点击，也不影响正文对比度。

设计图采用桌面画幅，并且存在两个不同的宽高比例。实际页面应按内容和断点适配，不能把字体、按钮和表格随整张画布一起缩小。图片没有覆盖加载、无数据、网络错误、表单错误、长文本和移动端状态，需要在现有交互基础上补齐。

## 已确认的实现差异

1. `WorkspaceEntry.vue` 在默认工作台渲染 `homepage.vue`，内容是 Mars Agent 主标题、四张案例卡和快捷入口。工作台参考图则要求任务输入区、三张能力卡和最近任务表。需要调整页面结构和入口关系。
2. `main.ts` 同时加载 refinement、redesign、prototype、screenshot 和 converted-dialogs 五份样式文件。修改前需要确认规则优先级和组件作用域，逐步收敛重复定义。
3. 登录页的 `--unit:min(1px,0.05637vw)` 会使桌面字体和控件随窗口变窄而缩小；弹窗的 `--u:calc(100vw / 1667)` 也采用全窗口缩放。需要确保桌面与移动断点之间仍有可读字号和足够的点击区域。
4. 已声明本地 Inter 和中文字体，但 screenshot 样式将 `--ac-font` 设置为系统字体。不同设备的字宽和换行可能不同，需要统一字体策略后再校准尺寸。
5. 现有已有截图按不同改造阶段命名，不能直接代表当前运行版本，应重新渲染当前源码并验收。
