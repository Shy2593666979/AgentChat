# 前端分批优化

以指定目录的 28 张 PNG 为基准，共分 5 批。同一批中的状态变体一起处理；每次只修改当前批涉及的页面和必要的共用组件。

| 批次 | 参考图 | 数量 | 状态 |
| --- | --- | --- | --- |
| 1：登录与异常入口 | 登录页、注册页、404页面 | 3 | 已修改；待浏览器视觉验收 |
| 2：工作台与智能体 | 工作台页、探索页（新参考）、智能体列表页、智能体编辑页-01、智能体编辑页-02 | 5 | 已修改；待浏览器视觉验收 |
| 3：模型与知识数据 | 模型列表页-01、模型列表页-02、添加模型页、知识库列表页、知识库文件管理页、数据看板页 | 6 | 已修改；待浏览器视觉验收 |
| 4：工具与配置 | 工具页-01、工具页-02、Skill技能列表页、Skill技能详情页、MCP服务列表页、个人中心页、系统配置页 | 7 | 已修改；待浏览器视觉验收 |
| 5：会话与任务流程 | 新建会话页、会话聊天页、Mars智能体会话页、MCP会话页、任务规划页、任务执行结果页、功能弹窗合集 | 7 | 已修改；待浏览器视觉验收 |

第 4、5 批可在批内按 2—3 页推进；“功能弹窗合集”在对应管理页面优化时提前核对，最终统一验收。

## 第 1 批变更

- 登录和注册页使用各自作用域下的共用样式，移除组件内重复的样式覆盖和整页缩放单位。
- 输入框保持至少 52px 高度、输入字号至少 16px；1100px 以下切换为单栏，700px 以下收起装饰内容。
- 使用项目内已有的 Inter 和中文字体，并校准品牌、标题、卡片、按钮及输入图标。
- 登录错误和注册错误在表单中显示，卡片随内容增长；提交中阻止重复请求。
- 注册页保留可选邮箱和现有密码最少 6 字符的规则，补充与规则一致的提示；密码和确认密码可分别切换可见性。未添加截图中没有实际协议内容支持的协议勾选项。
- 404 页使用现有公共侧栏，修复顶部无定义图标，个人入口读取当前用户信息，调整星球、404 字样和按钮比例。

## 验收

本批需检查 1774/1667px 参考画幅、1440px、1280px、1100px、700px、390px 和 320px。

登录/注册：默认、字段校验、服务错误、提交中、密码显隐、长错误信息、键盘焦点。

404：登录/未登录、侧栏展开/收起、头像缺失、返回工作台/上一页、移动端。

已通过应用配置下的 `vue-tsc --noEmit -p tsconfig.app.json` 类型检查和 Vite 生产构建。当前没有可连接的浏览器，视觉验收仍保持待办，不标记为已完成。


## 第 2 批变更

- `/workspace` 改为任务输入区、三张场景卡和真实任务记录表，保留原来的会话与任务规划入口。支持任务名称搜索、记录状态筛选、查看与确认删除。
- 场景卡填入对应任务建议；联网搜索状态传入现有任务规划流程。附件支持本地读取 TXT、Markdown、CSV、JSON，正文会随任务需求一起提交，最多 5 个文件、单文件 2MB、正文合计 16000 字符。知识库按钮进入现有管理页。
- 任务状态依据最近一次记录显示“已有结果”“已有规划”“暂无结果”，不根据截图伪造执行完成状态。缺少创建时间时显示“—”。
- `/homepage` 按新的 `探索页.png` 改为 Mars Agent 入口；`/construct` 保留“我的助手”列表，与 `/agent` 共用真实智能体数据和卡片操作。智能体列表保留主标题和分类按钮。
- 卡片按资源名称选择稳定的图标，补齐头像失败回退、长名称与描述处理、加载失败重试、空状态和会话创建中状态。桌面三列、中等屏幕两列、移动端单列。
- 编辑页改为基础信息、提示词与高级设置分区，保留双栏模型/能力/记忆配置。增加提示词模板、放大编辑器、资源搜索选择、已选资源移除和失败重试。保存校验失败时回到基础信息区。
- 移除编辑页自动插入的测试工具、MCP 和知识库，空资源列表保持真实空状态。模型卡显示真实供应商和类型；现有智能体保存接口没有温度参数，本批未添加温度滑块。参考图中的 Beta/升级入口也没有对应服务，不增加演示按钮。
- 探索页进入编辑、取消或保存后返回探索页；智能体列表进入编辑后返回智能体列表。编辑页使用自己的操作栏，避免公共顶部栏与保存按钮重叠。

本批已做应用类型、Vue 模板和 CSS 编译检查及生产构建；浏览器连接仍不可用，未进行截图对照和真实账号下的接口联调。视觉验收需覆盖工作台加载/空数据/错误、任务筛选、附件读取、卡片搜索与筛选、创建/编辑、资源选项错误与重试、提示词模板替换、头像上传和窄屏布局。

### 探索页参考更新

使用新图 `探索页.png` 替换之前的“我的助手”参考。探索页现在包含 Mars Agent 品牌主标题、任务输入框和自动构建智能体/深度搜索/AI 日报/知识库问答四张案例卡。发送内容传入现有 `/mars?message=...` 流程，案例传入已有的 `example_id=1—4` 流程；输入法组合输入时不触发快捷发送。

## 第 3 批变更

- 模型列表按两张参考图整理为分类计数、搜索、模型/提供方图标、类型标签、接口外链、更新时间和分页表格。内置模型保持只读，删除前确认。
- 添加模型与编辑模型共用双栏配置页，补齐新增入口、字段校验、API Key 显隐、失败提示和重试；使用接口实际支持的单个模型标识字段。
- 知识库列表包含装饰头图、四张真实统计卡、搜索排序、网格/列表切换、彩色文件夹卡片和分页。新增与编辑遵循后端名称和描述长度限制，描述允许清空。
- 文件管理页补齐面包屑、文档概览、文件类型图标、排序、状态筛选、跨页勾选、批量删除及部分失败反馈。上传进度与服务端文档状态分开显示，解析中每 15 秒刷新；超时显示状态待确认。切换知识库时取消未完成的上传并清理队列，解析请求绑定原知识库。
- 修正中文“处理失败”被识别为处理中，以及看板工作台活动详情跳转错误。看板的查看全部显示所选周期内的全部已读取活动，导出包含当前筛选条件及实际统计指标。
- 数据看板保留参考图中的四项指标、折线/柱状图和活动表格，统一字体、间距、焦点与窄屏排版；加载失败提供重试，已创建状态与已有结果使用不同颜色。
- 当前接口按日统计模型调用，图表明确标注按日统计；未提供工具调用数、单条活动 Token 或文档切分数的字段显示“—”，不填入参考图演示数据。知识库统计显示实际文档体积。

已通过应用配置类型检查、五个页面的 Vue 模板/CSS 编译、文件状态/时间/大小/外链工具回归检查及生产构建。浏览器连接返回空列表，未进行截图视觉验收及真实账号下的接口联调。后续需覆盖参考画幅及窄屏、长名称、分页筛选、表单错误、上传成功/失败/超时和跨页批量删除。


## 第 4 批变更

按工具/Skill、MCP、个人中心/系统配置三组推进，覆盖 7 张参考图（工具两张、Skill 列表/详情、MCP 服务、个人中心、系统配置），并核对相关功能弹窗。

- 工具页保留原生 SVG 装饰头图，整理搜索、分类计数、三列卡片、能力图标、标签与底部操作。提供头像失败回退、加载重试、详情、编辑、复制为新工具和确认删除。复制时清空鉴权凭据。
- 创建/编辑工具使用 Element Plus 弹窗，保留 OpenAPI JSON、方法预览、Bearer/Basic 鉴权与头像上传。校验错误就地展示，保存/上传中禁止重复提交及关闭弹窗。修正公用图片上传接口为后端实际注册的 `/api/v1/upload`。
- Skill 列表改为稳定的名称类别图标，不再因搜索/排序改变图标。搜索、来源筛选与排序使用真实数据，文件数量按文件树统计。
- Skill 详情通过 `/agent-skill?skill=<id>` 展示为页面，支持文件树展开、语法高亮编辑器、放大、Ctrl/Cmd+S、保存状态、添加空文件/上传 UTF-8 文本和确认删除。新增/删除范围保持 scripts/reference 目录；内置技能只读，文件深度超出现有保存接口能力时只读。切换文件、离开详情和浏览器关闭时保护未保存修改，保存中编辑器只读。编辑器及其模型在切换/退出时销毁。
- MCP 页采用双栏卡片、实际工具标签与三步引导。提供搜索、配置要求筛选、工具输入参数详情、基础连接信息/JSON 导入、头像、个人配置及确认删除。个人配置遵循后端的 key/value 数组格式；读取失败时禁止保存，JSON 与 URL 校验就地显示。
- MCP 接口未提供实时连接状态，卡片明确显示“需配置/无需配置”；对话入口进入现有 MCP 对话页，不声称自动选中此服务。编辑名称和头像时保留原连接配置，JSON 导入保留 headers 等字段。
- 个人中心整理双栏身份/资料卡、装饰背景、真实注册日期、资料字数、头像选择/上传与使用概览。会话记录、本人创建智能体、可见知识库文档及账户状态均读取真实接口。头像保存只提交已保存的简介，避免顺带保存尚未提交的输入。
- 当前用户更新接口只支持头像和简介，用户名及邮箱保持可见只读。系统配置页补齐 Monaco 编辑器、复制、JSON 校验、修改状态、快捷保存和取消恢复；配置未加载时禁用提交。

通过应用配置类型检查、五个页面的模板/CSS 编译、资源图标/错误解析回归检查及 Vite 生产构建。浏览器连接仍为空，截图对照、真实账号 CRUD、头像上传、MCP 服务连接与 Skill 文件接口联调尚未验收。

代码核查发现 `/api/v1/config` 的后端路由仅保留在 `api/v1/message.py` 的注释中。此批完成配置页布局和客户端错误处理，没有恢复或新建系统配置后端接口；实际读取/保存需后端提供此接口后联调。


## 第 5 批变更

按新建/普通会话、Mars/MCP、任务规划/执行结果三组推进，覆盖 7 张参考图，相关创建、删除、重新生成、步骤详情、离开提醒弹窗同步核对。

- 新建会话页保持为可进入的新建入口，移除自动跳转到旧会话和重复查询是否有历史的逻辑。加入报告、问题分析、代码解释建议卡，智能体选择、真实附件上传与创建状态。发送后创建会话并提交首条消息，消费 URL 中的首条消息参数，防止刷新重复提交。
- 会话侧栏使用真实会话名称与更新时间，按今天、昨天、过去 7 天、更早分组，支持搜索、选中状态、删除确认、错误重试及窄屏抽屉。模型显示来自智能体绑定模型，不增加接口不支持的切换控件。
- 普通聊天保留 Markdown、知识检索与事件展开，整理头像、消息边框、输入区和附件状态。补齐复制、反馈、再次提问、失败重试、停止接收、头像失败回退与“回到最新消息”。中文输入法组合输入和 Shift+Enter 不触发发送，输入框自动增高，用户上滚后不会强制拉回底部。
- 历史消息按角色顺序整理，保留连续用户/助手以及仅含事件的记录，事件状态以真实响应为准。历史请求和流式回调带版本检查，切换会话及卸载时取消流并忽略旧响应；附件上传失败与切换后的状态恢复不阻塞后续发送。
- Mars 页使用本页任务侧栏、用户需求、状态卡、可折叠分析过程与报告卡。支持继续提交新任务、记录切换、停止接收、复制和下载 Markdown。记录只存在当前页面，离开前提醒；不展示接口未提供的历史列表、资料篇数或分阶段耗时。
- MCP 对话页整理真实会话记录、Markdown 回答、调用事件和确认操作。提供参数查看、允许/拒绝、修改意见、停止接收、删除确认、错误反馈与滚动控制。只对当前最新消息的待确认请求显示操作按钮，不增加接口不支持的服务或模型选择器。
- 任务规划和结果共用 TaskWorkspace，分别提供需求/手册双栏与手册/流程/结果三栏。支持 Markdown 编辑/预览、重新生成、文本附件、联网搜索、当前灵寻支持的内置工具及 MCP 选择。读取历史时选最后一轮上下文，支持轮次选择和基于历史新建。
- 修正任务执行忽略已编辑指导手册、工具字段未按后端 plugins 提交的问题。步骤完成只来自实际 step_result 或历史 task.result，未记录状态保持未知；流程卡展示真实依赖和步骤响应，支持详情弹窗、复制和下载报告。没有执行耗时字段时不填入示例数值。
- 指导手册/任务响应可停止接收，保留已有内容；离开生成中的任务或放弃手册修改前提示。重新生成异常时保留可恢复的原手册，接口错误和主动停止分别显示。

本批还修正两处直接影响显示的后端问题：Mars 的 SSE 内容从 Python 字典字符串改为标准 JSON，支持中文、引号、换行和代码内容，前端移除 eval；会话列表合并智能体资料时保留会话名称、所有者及创建/更新时间，智能体名称另存 agent_name。点赞/反馈请求字段同时对齐后端 user_input/agent_output。

通过应用配置类型检查、9 个 Vue 文件模板/CSS 编译、生产构建、真实 HTTP 分片 SSE（UTF-8 逐字节、错误状态、非 SSE 响应、非法 JSON、停止接收）测试、历史整理/输入法保护测试，以及后端会话元数据合并和两条 Mars 输出路径的独立检查。预览路由可访问。

浏览器连接仍为空，未进行截图对照、真实账号 CRUD、真实模型/工具执行及授权联调。后端若没有自动重载，需要重新加载服务后验证 Mars JSON 输出和会话列表元数据修复。五批页面均已修改，视觉验收和真实接口联调仍保持待办。
