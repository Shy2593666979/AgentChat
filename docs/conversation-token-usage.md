# 会话 Token 用量

复用 `usage_stats` 表，在模型中定义可空的 `conversation_id` 列和索引，首次建表时统一创建，不执行旧库结构迁移。

普通会话发送时设置会话上下文，模型回调写入供应方实际返回的输入、输出 token。标题、摘要和子智能体模型调用继承同一会话上下文；切换智能体不会改变会话归属。输入与输出相加即累计总量，不重复加上历史消息的 `token_usage` 文本估算。

`GET /conversation/list` 批量返回各会话的 `input_tokens`、`output_tokens`、`total_tokens`、`model_calls`、`usage_available`。数据看板最近活动的 Token 用量列展示会话累计总量，悬停可查看输入与输出明细。该列累计范围为整个会话，区别于顶部按所选时间汇总的指标。

原 `POST /usage`、`POST /usage_count` 增加可选 `conversation_id` 参数，可在原模型、智能体与时间范围条件基础上查询指定会话。所有查询都按当前用户过滤。

回调兼容 `AIMessage.usage_metadata` 与供应方 `llm_output.token_usage`；同一调用的重复回调去重。自定义模型已直接记录用量时，通过标记避免回调再次写入。不返回用量的供应方不会被当作零消耗或用文本估算替代。

旧记录缺少会话 ID，无法准确追溯到某个会话，因此不做猜测回填。没有关联用量的会话显示“—”；旧记录仍参与原模型、智能体总用量统计。新发送产生的记录会开始累积会话用量。中途停止时，只有供应方实际返回的用量会被记录，不推算未收到的数据。
